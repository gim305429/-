# 부캉이 AOS

의림지 수로에서 펼쳐지는 3대3 웹 게임입니다. 물고기 미니언과 함께 라인을 밀고, 포탑 두 개를 부순 뒤 상대 넥서스를 먼저 깨면 승리합니다. 한 판은 보통 15분 안팎입니다.

- 혼자서 봇과 연습하거나, 방을 만들어 방 코드로 친구와 함께 플레이할 수 있어요. 대기실과 경기 중에 채팅을 쓸 수 있어요.
- 챔피언: 부캉이, 복어, 날치, 물뱀, 피라냐 (각각 스킬 3개 + 궁극기)
- 상점: 기본 아이템 9종과, 기본 아이템을 조합하는 상위 아이템 6종
- 잘 크고 있는 적에게는 현상금이 붙어서, 잡으면 추가 골드를 받아요.
- 휴대폰(조이스틱·버튼)과 PC(키보드·마우스) 모두 지원

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 기본 공격 (누르는 동안 사거리 표시) |
| Q · E · F | 스킬 1 · 2 · 3 (Lv 1 · 2 · 3에 해금) |
| R | 궁극기 (Lv 6, 물뱀은 Lv 11) |
| Shift | 대시 |
| B | 귀환 |
| P / Tab | 상점 / 점수판 |
| Enter | 채팅 |

조준이 필요한 스킬은 키를 누른 채 마우스로 방향을 정하고 떼면 나갑니다. 휴대폰에서는 스킬 버튼을 누른 채 끌어서 조준해요.

# 세명 스트라이크 (`semyung/`)

세명대학교 본관을 무대로 한 3대3 능력자 FPS입니다. 본관을 순찰하는 교장(적대 NPC)은 팀 상관없이 아무나 공격하고, 처치하면 30초간 버프를 받아요.

- 주소: `https://gim305429.github.io/-/semyung/` (GitHub Pages가 켜져 있을 때)
- 혼자 봇과 하거나, **방 만들기**로 방 코드/초대 링크를 보내 최대 6명이 같이 할 수 있어요. 빈자리는 봇이 채워요.
- 목숨 3개, 기절하면 팀원이 F(휴대폰은 살리기 버튼)를 4초 눌러 부활
- 캐릭터 7명: 오세훈, 조경인, 강진우, 송영진, 김민찬, 김태우, 김정우 (각각 스킬 Q · E + 궁극기 X)
- PC(키보드·마우스)와 휴대폰(조이스틱·터치 버튼) 모두 지원
- 적은 빨간 외곽선, 아군은 파란 외곽선, 교장은 노란 외곽선으로 보여요

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 / 좌클릭 | 조준 / 사격 |
| Q · E | 스킬 |
| X | 궁극기 |
| 1~4, 휠 | 무기 (4번 쿠나이는 송영진 궁극기 중) |
| R · Space · Shift | 재장전 · 점프 · 걷기 |
| F (길게) | 기절한 팀원 살리기 |
| Space / 앞으로 밀기 | 창틀·책상·낮은 벽 넘기 |
| C | 은신 (송영진 궁극기 중) |
| Tab · Esc | 점수판 · 조준 해제 |

## 멀티플레이 구조

서버 없이 PeerJS(WebRTC)로 연결합니다. 방장 브라우저가 게임을 계산하고 참가자에게 상태를 보내요. 방장이 나가면 게임이 끝나고, 참가자가 나가면 봇이 이어받아요. 학교·회사 와이파이처럼 막힌 네트워크에서는 연결이 안 될 수 있어요.
