# 부캉이 AOS

의림지 수로에서 펼쳐지는 3대3 웹 게임입니다. 물고기 미니언과 함께 라인을 밀고, 포탑 두 개를 부순 뒤 상대 넥서스를 먼저 깨면 승리합니다. 한 판은 보통 15분 안팎입니다.

- 혼자서 봇과 연습하거나, 방을 만들어 방 코드로 친구와 함께 플레이할 수 있어요. 대기실과 경기 중에 채팅을 쓸 수 있어요.
- 챔피언: 부캉이, 복어, 날치, 물뱀, 피라냐 (각각 스킬 3개 + 궁극기)
- 상점: 기본 아이템 9종과, 기본 아이템을 조합하는 상위 아이템 6종
- 잘 크고 있는 적에게는 현상금이 붙어서, 잡으면 추가 골드를 받아요.
- 휴대폰(조이스틱·버튼)과 PC(키보드·마우스) 모두 지원

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 기본 공격 (누르는 동안 사거리 표시) |
| Q · E · F | 스킬 1 · 2 · 3 (Lv 1 · 2 · 3에 해금) |
| R | 궁극기 (Lv 6, 물뱀은 Lv 11) |
| Shift | 대시 |
| B | 귀환 |
| P / Tab | 상점 / 점수판 |
| Enter | 채팅 |

조준이 필요한 스킬은 키를 누른 채 마우스로 방향을 정하고 떼면 나갑니다. 휴대폰에서는 스킬 버튼을 누른 채 끌어서 조준해요.

# 세명 스트라이크 (`semyung/`)

세명대학교 본관을 무대로 한 3대3 능력자 FPS입니다. 본관을 순찰하는 교장(적대 NPC)은 팀 상관없이 아무나 공격하고, 처치하면 30초간 버프를 받아요.

- 주소: `https://gim305429.github.io/-/semyung/` (GitHub Pages가 켜져 있을 때)
- 혼자 봇과 하거나, **방 만들기**로 방 코드/초대 링크를 보내 최대 6명이 같이 할 수 있어요. 빈자리는 봇이 채워요.
- 목숨 3개, 기절하면 팀원이 F(휴대폰은 살리기 버튼)를 4초 눌러 부활
- 캐릭터 7명: 오세훈, 조경인, 강진우, 송영진, 김민찬, 김태우, 김정우 (각각 스킬 Q · E + 궁극기 X)
- PC(키보드·마우스)와 휴대폰(조이스틱·터치 버튼) 모두 지원
- 적은 빨간 외곽선, 아군은 파란 외곽선, 교장은 노란 외곽선으로 보여요

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 / 좌클릭 | 조준 / 사격 |
| Q · E | 스킬 |
| X | 궁극기 |
| 1~4, 휠 | 무기 (4번 쿠나이는 송영진 궁극기 중) |
| R · Space · Shift | 재장전 · 점프 · 걷기 |
| F (길게) | 기절한 팀원 살리기 |
| Space / 앞으로 밀기 | 창틀·책상·낮은 벽 넘기 |
| C | 은신 (송영진 궁극기 중) |
| Tab · Esc | 점수판 · 조준 해제 |

## 멀티플레이 구조

서버 없이 PeerJS(WebRTC)로 연결합니다. 방장 브라우저가 게임을 계산하고 참가자에게 상태를 보내요. 방장이 나가면 게임이 끝나고, 참가자가 나가면 봇이 이어받아요. 학교·회사 와이파이처럼 막힌 네트워크에서는 연결이 안 될 수 있어요.

# 바람의 초원 원정대 (`meadow/`) — 데모

파스텔 초원을 자유롭게 돌아다니는 1인칭 협동 로그라이트 RPG입니다. 직업을 골라 넓은 오픈맵에 나가, 거점을 정화하고 중간 보스를 잡아 북쪽 유적의 봉인을 풀고, 최종 보스를 쓰러뜨리면 성공이에요.

- 주소: `https://gim305429.github.io/-/meadow/` (GitHub Pages가 켜져 있을 때)
- **멀티플레이**: 마을의 `방 만들기` → 5자리 방 코드나 초대 링크(`?room=코드`)를 보내면 최대 4명. 빈자리는 봇 동료가 채워요. 혼자 해도 봇 0~3명과 함께 갈 수 있어요
  - 방장 브라우저가 게임을 돌리고(PeerJS·WebRTC), 나머지는 접속만 해요. 방장이 나가면 판이 끝나요
- **오픈맵**: 꽃 초원 · 유적 언덕 · 버섯 숲 · 바람 절벽 · 수정 호수 5개 지역. 마을에서 멀어질수록 강해져요
  - 거점 6곳(정화하면 카드·상자), 떠도는 몬스터 무리, 숨은 보물 상자, 중간 보스 둥지, 봉인된 최종 보스 유적(거점 3곳 + 중간 보스로 해제)
  - 4분마다 위험도가 올라 몬스터가 더 많고 세져요
- **기믹**: 상승 기류(밟으면 높이 뛰고, 공중에서 점프를 누르고 있으면 활공), 폭발 버섯, 번개 수정(맞히면 주변 적에게 연쇄 번개), 치유의 샘, 가시 덤불(느려짐)
- **레벨업 능력치**: 레벨마다 3점을 공격·체력·민첩·치명·정신에 찍어요. 한 능력치 10점·20점마다 특성이 열려요. 마을에서 재료 50으로 초기화
- **장비 모양**: 직업별 무기 3종 디자인(검과 방패, 지팡이, 활) × 등급 색. 마법사·성직자는 지팡이 끝에서 마법이 나가고, 궁수는 평소엔 활을 내려 들다가 공격할 때 팔을 뻗어 활을 눕혀 시위를 당겨요
- 직업 4개, 강화 카드 100장(카드 고르는 중에도 게임은 계속), 몬스터 12종 + 정예 접두어, 보스 4종
- 진행은 브라우저에 저장돼요 (다른 기기와는 이어지지 않음)

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 · 좌클릭 · 우클릭 | 시점 · 공격 · 직업 보조(막기, 치유, 순간이동, 조준) |
| Q | 직업 스킬 |
| Shift · Space | 대시 · 점프 (공중에서 누르고 있으면 활공) |
| E | 줍기·상자 열기·쓰러진 동료 살리기(3초) |
| Tab · T · M · Esc | 원정 가방 · 능력치 · 지도 · 일시정지 |

휴대폰에서는 화면 왼쪽 아무 곳이나 눌러 이동하고, 오른쪽을 끌어 시점을 돌려요. 공격 버튼을 누른 채 끌면 조준이 따라와요.

## 파일

- `meadow/js/data.js` 직업·카드·몬스터·보스·장비·지역·능력치 표
- `meadow/js/art.js` 셀 셰이딩 그래픽 (무기·동료·지형·기믹 모델)
- `meadow/js/world.js` 오픈맵 생성 (같은 시드면 모두에게 같은 맵)
- `meadow/js/sim.js` 전투·몬스터·보스·기믹·봇 · `meadow/js/run.js` 판 진행·멀티 동기화·카메라
- `meadow/js/core.js` 공용 상태·저장·효과 · `meadow/js/net.js` 방 코드 연결 · `meadow/js/ui.js` 화면과 입력
- `meadow/lib/three.module.min.js` three.js r160 · `meadow/assets/manifest.json` 그래픽 교체용 목록
