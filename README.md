# 부캉이 AOS

의림지 수로에서 펼쳐지는 3대3 웹 게임입니다. 물고기 미니언과 함께 라인을 밀고, 포탑 두 개를 부순 뒤 상대 넥서스를 먼저 깨면 승리합니다. 한 판은 보통 15분 안팎입니다.

- 혼자서 봇과 연습하거나, 방을 만들어 방 코드로 친구와 함께 플레이할 수 있어요. 대기실과 경기 중에 채팅을 쓸 수 있어요.
- 챔피언: 부캉이, 복어, 날치, 물뱀, 피라냐 (각각 스킬 3개 + 궁극기)
- 상점: 기본 아이템 9종과, 기본 아이템을 조합하는 상위 아이템 6종
- 잘 크고 있는 적에게는 현상금이 붙어서, 잡으면 추가 골드를 받아요.
- 휴대폰(조이스틱·버튼)과 PC(키보드·마우스) 모두 지원

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 기본 공격 (누르는 동안 사거리 표시) |
| Q · E · F | 스킬 1 · 2 · 3 (Lv 1 · 2 · 3에 해금) |
| R | 궁극기 (Lv 6, 물뱀은 Lv 11) |
| Shift | 대시 |
| B | 귀환 |
| P / Tab | 상점 / 점수판 |
| Enter | 채팅 |

조준이 필요한 스킬은 키를 누른 채 마우스로 방향을 정하고 떼면 나갑니다. 휴대폰에서는 스킬 버튼을 누른 채 끌어서 조준해요.
